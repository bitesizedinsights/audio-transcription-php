# Audio Transcription PHP

> PHP client for audio and video transcription (speech to text, SRT/VTT subtitles) via Apify, returns typed DTOs.

Key facts:
- Package: `bitesizedinsights/audio-transcription`
- Install: `composer require bitesizedinsights/audio-transcription`
- PHP: ^8.3, Guzzle ^7
- Namespace: `AudioTranscription`
- Entry class: `AudioTranscription\Client`
- Auth: Apify API token, set via `Client::setApifyKey()`, falls back to env `APIFY_API_TOKEN` or `APIFY_TOKEN`

## Docs
- [README](https://github.com/bitesizedinsights/audio-transcription-php/blob/master/README.md): usage
- [Actor](https://apify.com/bite-sized-insights/transcription): the underlying Apify Actor

## API
- `Client::__construct(?Config $config = null, ?GuzzleHttp\ClientInterface $http = null)`
- `Client::setApifyKey(string $apiKey): static` - sets the Apify API key; without it `APIFY_API_TOKEN` or `APIFY_TOKEN` is read from the environment, and `MissingApiKeyException` is thrown on the first API call if neither is set
- `Client::transcribe(array $urls = [], Language $language = Language::Auto, bool $translateToEnglish = false, array $subtitleFormats = [], bool $diarize = false, ?int $numSpeakers = null, int $maxMinutesPerFile = 60, bool $withSummary = false, bool $withTags = false, bool $with5w1h = false, bool $withSentiment = false, array $feedUrls = [], int $maxEpisodesPerFeed = 5): Transcript[]` - starts one run for all URLs (1-100, links and feed episodes together at most 100), waits for it, returns one Transcript per URL
- `Client::start(...same arguments as transcribe()): Run` - starts the run and returns at once; `getRun(string $runId): Run` - one lookup; `wait(Run|string $run, ?int $timeout = null): Run` - polls until SUCCEEDED, throws ApiException on FAILED/ABORTED/TIMED-OUT or timeout (default Config::$timeout), keeps polling on ABORTING/TIMING-OUT; `results(Run|string $run): Transcript[]` - dataset of a SUCCEEDED run, ApiException otherwise; `abort(Run|string $run): Run`; `transcribe()` is results(wait(start(...))); POST (start, abort) is retried only on 429 or a failed connection
- `Config(string $actorId = 'bite-sized-insights/transcription', string $baseUrl = 'https://api.apify.com/v2', int $timeout = 600, int $requestTimeout = 90)`
- DTOs (all `final readonly`, `fromArray(array)`):
  - `Transcript`: url: string, status: TranscriptStatus, translated: bool, transcribedSeconds: float, minutesTranscribed: int, truncated: bool, segments: Segment[], language: ?string, languageProbability: ?float, durationSeconds: ?float, text: ?string, speakers: ?int, diarization: ?DiarizationStatus, srt: ?string, vtt: ?string, errorCode: ?string, error: ?string, summary: ?Summary, tags: ?Tags, fiveW1h: ?array, sentiment: ?SentimentResult, analysisTruncated: bool; chunks: Transcript::chunks(maxSeconds=60.0, maxCharacters=1000, overlapSegments=0, splitOnSpeaker=true, pauseSeconds=null): Chunk[] (segments are never split; Chunk: index: int, start: float, end: float, text: string, segmentIds: int[], speakers: string[]; getDuration(), getSpeaker(): ?string, toArray()), Transcript::getChunkUrl(Chunk): string; helpers Segment::getTimestamp(): string, Transcript::getSegmentUrl(Segment): string, getTimestampedText(): string, saveSrt(path), saveVtt(path) (RuntimeException if not requested); podcast feeds: transcribe(urls=[], ..., feedUrls: string[] = [], maxEpisodesPerFeed: int = 5 (1-50)); urls or feedUrls required (InvalidArgumentException), one Transcript per file (links first, then episodes newest first; an unreadable feed gives one failed row); Transcript adds minutesCached: int, message: ?string, sourceFeed/episodeTitle/episodePublished/episodeGuid: ?string, isSkipped(), needsRerun() (partial or skipped: call again with the same arguments, finished work is cached 90 days and not billed twice), getEpisodePublishedAt(); TranscriptStatus::Skipped; ErrorCode RunTimeLimit, InvalidFeed, NoEpisodes; Config runTimeout: ?int (Apify run time limit, default Actor 300 s; keep timeout above it); retries: Config maxRetries=3, retryBaseDelay=1.0, retryMaxDelay=30.0 (429/5xx/connection; POST run start only on 429 or failed connection); serialization: all DTOs implement JsonSerializable and toArray() in the Actor's snake_case shape, fromArray(toArray()) restores them; helpers isSuccessful(), isPartial(), isFailed(), getErrorCode(): ?ErrorCode, getSummaryText(): ?string, getTags(): string[], getSentiment(): ?Sentiment, getSegmentCount(): int
  - `Run`: id: string, status: RunStatus, defaultDatasetId: ?string, startedAt: ?string, finishedAt: ?string; isFinished(), isSuccessful(), toArray() (Apify field names), fromArray()
  - `Segment`: id: int, start: float, end: float, text: string, speaker: ?string (set with diarize); helper getDuration(): float
  - `Summary`: summary: string, originalLength: ?int, summaryLength: ?int, compressionRatio: ?float
  - `Tags`: tags: string[], count: int
  - `SentimentResult`: sentiment: ?Sentiment, confidence: ?float
- Enums:
  - `Language`: Auto ('auto') plus 100 languages, e.g. English ('en'), German ('de'), Cantonese ('yue')
  - `SubtitleFormat`: Srt ('srt'), Vtt ('vtt')
  - `TranscriptStatus`: Success, Partial, Skipped, Failed
  - `DiarizationStatus`: Ok, SkippedTime, Failed
  - `ErrorCode`: BlockedUrl, DownloadFailed, TooLarge, UnsupportedFormat, InvalidMedia, NoAudio, TooLong, NoSpeech, TranscriptionFailed, ServiceUnavailable, RunTimeLimit, InvalidFeed, NoEpisodes
  - `Sentiment`: Positive, Neutral, Negative
  - `RunStatus`: Ready, Running, Succeeded, Failed, Aborting, Aborted, TimingOut ('TIMING-OUT'), TimedOut ('TIMED-OUT'); isFinished(), isFailure()
- Exceptions:
  - `RateLimitException` (extends ApiException, has `retryAfter` seconds): HTTP 429
  - `ApiException` (has `?string $runId`): other HTTP errors, connection failures, malformed JSON, run status FAILED/ABORTED/TIMED-OUT, run not finished within Config::$timeout, missing dataset ID, unmappable dataset item (message names the index)
  - A file that cannot be transcribed does not throw; its Transcript has status Failed with errorCode and error

## Example

```php
<?php

use AudioTranscription\Client;
use AudioTranscription\SubtitleFormat;

$client = (new Client())->setApifyKey(getenv('APIFY_TOKEN'));

$transcripts = $client->transcribe(
    urls: ['https://example.com/podcast.mp3'],
    subtitleFormats: [SubtitleFormat::Srt],
);

foreach ($transcripts as $transcript) {
    echo $transcript->isSuccessful() ? $transcript->text : $transcript->error, "\n";
}
```
